## Versión 2026
La versión pública actual es una página estática independiente, diseñada para presentar mi experiencia profesional como Ingeniero en Sistemas Computacionales, consultor y líder de proyectos Odoo.

**Publicación:** GitHub Pages utiliza la rama `gh-pages`, archivo `index.html` en la raíz. La versión 2026 está escrita en HTML/CSS sin dependencias externas.

**Importante:** Esta rama `main` conserva el portafolio anterior basado en Create React App como respaldo histórico. **No ejecutar `npm run deploy` desde `main` sin planear la migración:** ese comando podría sobrescribir `gh-pages` con la antigua versión React.
